OPENHTPC 1.3.2 RC4 — PATINA / PUBLIC PRERELEASE

Release tag: v1.3.2-rc4
This archive contains the source, the tested Flex runtime and managed
installer components for the OPENHTPC Release Candidate 4.
Verify the downloaded OpenHTPC-1.3.2-RC4.tar.gz archive using the matching
OpenHTPC-1.3.2-RC4.tar.gz.sha256 file from the release's assets.
Normal RC4 installation does not upload diagnostic logs automatically.
There is no separate Recently Added/SD/1080p/UHD filter panel in RC4.
Optional release screenshots are captured in SDL offscreen QA mode and
include third-party movie poster artwork; they are illustrative, not
proof of physical gamepad operation.
